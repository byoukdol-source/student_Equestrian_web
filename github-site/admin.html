학생승마 관리자 화면

담당 승마장의 신청 목록 조회 및 안내 콘텐츠 수정
지금 사용 중인 앱(카카오톡 등)의 내부 브라우저에서는 구글 로그인이 작동하지 않아요.
아래 순서대로 사파리(아이폰) 또는 크롬(안드로이드) 같은 기본 브라우저 앱으로 열어주세요.

1. 화면 오른쪽 아래(또는 오른쪽 위) ··· 또는 공유 버튼을 눌러주세요.
2. "다른 브라우저로 열기" 또는 "Safari로 열기"를 선택해주세요.
(메뉴가 안 보이면 아래 버튼으로 주소를 복사한 뒤, 사파리/크롬 앱을 직접 열어 주소창에 붙여넣어 주세요.)
주소를 복사했어요. 사파리/크롬 앱을 열어 주소창에 붙여넣어 주세요.
'*'로 시작하는 줄은 방문자 화면에서 빨간색으로 강조되어 표시됩니다. 오픈일이 특정 날짜로 정해진 경우엔 위 첫 줄 문구 대신 "{날짜}부터 오픈됩니다."가 자동으로 표시되고, 이 추가 안내는 그 아래 그대로 표시됩니다.
* 참고: 당첨확인 명단의 "구분" 값은 이제 학생승마(일반)/학생승마(생활)/학생승마(재활) 중 하나로 관리됩니다. 일반은 기존과 동일하게 보험가입+입금이 필요하고, 생활/재활은 전액지원 대상이라 방문자 화면의 보험가입 탭에 계좌 대신 "전액 지원" 문구가 자동으로 표시됩니다.
체크를 켜고 시간대를 한 줄에 하나씩 "라벨,정원" 형식으로 입력하면(예: 화 3:00,4 / 수 3:00,4), 보험가입정보 제출이 완료된 직후 방문자가 실시간 잔여좌석을 보면서 선착순으로 수업시간을 선택하는 화면으로 자동 이동합니다. 체크를 끄면(기본값) 지금까지와 동일하게 보험가입 제출만으로 끝나고, 수업시간은 승마장에서 별도로 안내합니다.
체크하면 방문자 화면의 포니등급신청 탭에 신청폼 대신 "접수 시작 준비 중입니다. 문의는 카카오채널로 부탁드립니다." 문구가 표시됩니다. (이미 신청을 마쳤거나 인증에 합격한 학생에게는 잠금과 무관하게 기존처럼 본인 상태가 그대로 보입니다.)
체크를 켜고 안내문구/이미지 중 하나라도 입력하면, 방문자 화면 승마장안내 맨 위 운영시간 옆에 빨간색 '일정확인' 버튼이 나타나고, 누르면 여기 입력한 내용이 팝업으로 보여집니다.
위 재활 전용 칸은 학생승마(재활)로 분류된 학생에게만 보입니다. 비워두면 재활 학생에게도 일반 수업방법·출석·보강 내용이 그대로 보여요.
이미지는 파일 업로드가 아니라 이미지가 올라가 있는 링크(URL)를 붙여넣는 방식입니다. 구글 드라이브에 이미지를 올린 뒤 "링크가 있는 모든 사용자"로 공유 설정하고, 공유 링크(예: .../file/d/파일ID/view)를 그대로 붙여넣으시면 미리보기가 뜨는 링크로 자동 변환해서 저장합니다.
카카오채널을 비워두면 방문자 화면에는 해당 줄이 "준비중"으로 표시됩니다. 오시는 길은 지도 링크 대신 주소를 그대로 텍스트로 보여줍니다 — 비워두면 "준비중"으로 표시됩니다. (참고: 문의 화면의 'KRA(마사회)' 박스와 시청 관련 안내는 2026-08-04부터 고정 문구로 바뀌어 더 이상 여기서 설정하지 않습니다.)
* 여기서 저장한 내용은 방문자가 다음에 페이지를 열거나 새로고침할 때 자동으로 반영됩니다.
